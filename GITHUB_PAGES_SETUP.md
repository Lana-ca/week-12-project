# Deploy Family Grimoire to GitHub Pages

Your website is ready to deploy! Follow these simple steps:

## Step 1: Enable GitHub Pages

1. Go to your GitHub repository: **https://github.com/Lana-ca/week-12-project**

2. Click on **Settings** (top menu)

3. In the left sidebar, click **Pages**

4. Under **Build and deployment**:
   - **Source**: Select "GitHub Actions"

5. That's it! GitHub Actions will automatically build and deploy your site.

## Step 2: Wait for Deployment (2-3 minutes)

1. Go to the **Actions** tab in your repository

2. You'll see a workflow running called "Deploy to GitHub Pages"

3. Wait for it to complete (green checkmark)

## Step 3: Visit Your Live Website! 🎉

Your Family Grimoire will be live at:

**https://lana-ca.github.io/week-12-project/**

Every time you push code to GitHub, your website will automatically rebuild and redeploy!

## Troubleshooting

**Deployment failed?**
- Check the Actions tab for error messages
- Make sure GitHub Pages is enabled in Settings

**Page shows 404?**
- Wait a few minutes after first deployment
- Clear your browser cache
- Make sure the workflow completed successfully

**Still having issues?**
- Check that the repository is public (required for free GitHub Pages)
- Verify the branch name in `.github/workflows/deploy.yml` matches your branch
